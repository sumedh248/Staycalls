================================================================================
                           StayCalls PROJECT
================================================================================

PROJECT OVERVIEW:
StayCalls is a Node.js/Express-based web application for managing travel 
listings, user reviews, and authentication. It provides a platform for users 
to browse accommodations, write reviews, and manage their profiles.

TECHNOLOGY STACK:
- Backend: Node.js with Express.js framework
- Frontend: EJS templating engine for server-side rendering
- Styling: CSS (custom styling)
- Image Management: Cloudinary integration
- Database: Mongoose (MongoDB driver implied by schema patterns)

================================================================================
                            KEY FEATURES
================================================================================

✓ User Authentication (Sign up & Login)
✓ Create, Read, Update, Delete (CRUD) listings
✓ Review system for listings
✓ Image upload and management via Cloudinary
✓ Responsive UI with EJS templates
✓ Custom error handling
✓ Flash messages for user feedback

================================================================================
                         GETTING STARTED
================================================================================

1. Install dependencies: npm install
2. Configure Cloudinary API credentials in cloudinary.js
3. Set up MongoDB connection string
4. Run seed data (optional): npm run seed
5. Start server: npm start
6. Access application at http://localhost:3000 (or configured port)
